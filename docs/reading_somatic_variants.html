Reading Somatic Variants

What the output files mean, field by field — with real values from this pipeline.

Two kinds of mutation

Before you can read a VCF, you need to know what Mutect2 is looking for — and what it's trying to ignore.

Germline
Born with it

A variant present in every cell of the body, inherited from a parent. About 3 million per person. These are normal — not disease-causing (usually) — and we want to exclude them from a somatic callset.

Somatic
Acquired in the tumor

A mutation that arose after conception, in a single cell that then divided. Present only in the tumor (and its descendants). These are what we want to find — they drive cancer.

The matched normal sample (HCC1143BL) is the key to separating these. Any variant seen in the normal is, by definition, germline. Mutect2 subtracts it. What remains — present in tumor but absent in normal — is a somatic candidate.

Variant allele frequency (VAF / AF)

This is the single most important number on a somatic variant. It answers: in what fraction of reads does the mutation appear?

Formula: AF = alt_reads / (ref_reads + alt_reads)

Why is it never 50% or 100% in tumors?

Tumor heterogeneity
Not all cells are identical

A mutation that arose early is in all tumor cells (~50% VAF in a diploid clone). A later mutation is only in a subclone — maybe 20% of cells → ~10% VAF.

Normal contamination
Dilution from normal cells

A tumor biopsy always contains some normal stromal cells. If 40% of cells are normal, a clonal mutation appears at 50% × 60% = ~30% VAF.

In our data, PASS variants range from ~10% to ~40% VAF — typical for a heterogeneous breast cancer with normal cell admixture.

Rule of thumb: VAF ~50% in normal = germline heterozygous. VAF ~100% in normal = germline homozygous. VAF 5–40% only in tumor, ~0% in normal = somatic candidate.

INFO fields — per-variant statistics

The INFO column carries Mutect2's statistical evidence. These are the fields that decide whether a variant becomes PASS or gets filtered.

Field Meaning & how to read it
TLOD Tumor Log Odds. The primary signal: how many times more likely is this a real somatic mutation than a sequencing error? Expressed as a log10 odds ratio.

TLOD 3
weak
TLOD 6.3
default threshold
TLOD 12+
high confidence

Our first example variant had TLOD=12.19 — well above threshold.
NLOD Normal Log Odds. How confident are we that the normal sample is truly homozygous reference? Low NLOD means the normal also has alt reads → the variant might be germline.

NLOD < 2.2 → Mutect2 is uncertain about the normal — flag for review.
NLOD 20+ → Normal is very clean, strong evidence it's somatic.
NALOD Normal Artifact Log Odds. Specifically tests: is this variant consistent with a germline artifact in the normal? Positive = somatic; negative = some alt reads in normal too.

A slightly negative NALOD (like −0.95 or −1.28) doesn't automatically fail the variant — FilterMutectCalls weighs it against all other evidence. But a strongly negative value raises suspicion.
POPAF Population Allele Frequency (in gnomAD, log scale). How common is this alt allele in the healthy population?

POPAF = 6.0 = not in gnomAD at all → novel → likely somatic.
POPAF < 2.0 = common in population → almost certainly germline, not somatic.
DP Total depth. Total reads covering this position (ref + alt). Low depth = unreliable calls. Anything below 10× is very uncertain; good somatic calling needs 20–50× tumor depth.
MBQ Median Base Quality for ref reads, alt reads. Base quality = how confident the sequencer was when it called that base. Below 20 = 1 error per 100 bases = unreliable. 30+ = good.
MMQ Median Mapping Quality. How uniquely does this read map to the genome? 60 = uniquely mapped (best). Below 30 = the read could belong to multiple locations → the alt allele might be a misalignment artifact from a repeat region.

FORMAT fields — per-sample read counts

The FORMAT column defines the structure; the last two columns contain the actual values for NORMAL (first) and TUMOR (second).

FieldMeaning & how to read it
GT Genotype. 0 = reference allele, 1 = alternate allele.

0/1 heterozygous (one ref copy, one alt copy) — typical for somatic mutation in a diploid tumor.
0/0 homozygous reference — what you want to see in the normal.
1/1 homozygous alternate — either loss of heterozygosity (LOH) or a germline homozygous variant.
AD Allele Depth. Format: ref_reads,alt_reads.

Example: Tumor AD=22,7 → 22 reads say REF (T), 7 reads say ALT (C). Total = 29 reads. The 7 alt reads are our evidence for the mutation. This is the raw read count — always check it. An AF of 30% from 3/10 reads is much less reliable than 30% from 30/100.
AF Allele Frequency = VAF. Computed as alt_reads / total_reads. This is the most biologically meaningful number on the line. See the VAF section above.
DP Depth per sample. Total reads at this position for this sample. May differ slightly from INFO DP because INFO DP aggregates both samples.
F1R2 / F2R1 Orientation counts. F1R2 = reads where the first read of the pair is on the forward strand. F2R1 = first read on reverse strand. For a real variant, you expect roughly equal counts on both orientations.

If alt reads are almost all F1R2 with very few F2R1 (or vice versa), this is the signature of an orientation artifact — a systematic sequencing error, not a true mutation. LearnReadOrientationModel detects and flags these.
SB Strand Bias. Format: ref-fwd, ref-rev, alt-fwd, alt-rev.

Example: SB=3,19,2,5 — alt reads split 2 forward / 5 reverse, ref reads split 3 / 19. Severe imbalance in the alt counts (e.g., 8/0 or 0/8) triggers the strand_bias filter.

Orientation artifacts — what F1R2/F2R1 catches

OxoG (oxidative)
G → T on one strand

Oxidized guanine (8-oxoG) base-pairs with adenine instead of cytosine during sequencing. Appears as G→T only on reads where the damaged base was read on the forward strand.

FFPE (formalin)
C → T deamination

Formalin fixation causes cytosine deamination to uracil, read as thymine. Appears as C→T enriched on one strand orientation — a classic FFPE artifact seen in clinical tissue samples.

Both patterns look exactly like real mutations in the VCF — same base change, similar depth. The only tell is the strand imbalance in F1R2 vs F2R1 counts.

The pipeline's solution:

  1. Mutect2 collects F1R2/F2R1 counts for every candidate alt allele → f1r2.tar.gz
  2. LearnReadOrientationModel builds a per-trinucleotide-context artifact model → artifact_prior.tar.gz
  3. FilterMutectCalls multiplies each variant's somatic probability by the artifact prior — if the strand pattern matches a known artifact, the posterior drops below the threshold → filtered
In our chr22 data, the orientation filter removed only ~0.02 estimated false positives — the data is clean (cell line DNA, not FFPE). In clinical tissue samples this filter removes far more.

A PASS variant, decoded

chr22     11067996   .   A   T     .    PASS     ...TLOD=4.96;POPAF=6.00;GERMQ=93;...    GT:AD:AF:DP:...   0/0:18,0:0.05:18    0/1:28,2:0.10:30
What we readWhat it means
FILTER = PASS FilterMutectCalls evaluated all criteria and this variant passed them all.
REF=A, ALT=T A→T transversion at chr22:11,067,996. This is a somatic substitution.
TLOD = 4.96 Below the typical default of 6.3, but FilterMutectCalls uses a Bayesian posterior, not a hard cutoff — this variant's other evidence pushed it over threshold.
POPAF = 6.00 Not in population databases. Novel variant — strong prior for somatic.
GERMQ = 93 93% probability this is somatic, not germline. Very confident.
Normal: GT=0/0, AD=18,0 Normal has 18 ref reads and zero alt reads. The normal is perfectly clean — this is not germline.
Tumor: GT=0/1, AD=28,2, AF=0.10 Tumor has 28 ref + 2 alt reads. VAF = 10%. Low depth (30 total) but with a clean normal and good GERMQ, this passes. Likely a subclonal mutation.

Four questions for any variant

  • 1
    Is the tumor signal strong? Check TLOD and tumor AD. TLOD > 6 and at least 3–5 alt reads gives confidence. One or two alt reads out of 10 total is marginal even if AF looks interesting.
  • 2
    Is the normal truly clean? Check normal AD and NLOD. Normal AD should be something like 40,0 or 40,2 (a few alt reads is noise). If the normal has 10+ alt reads, suspect germline.
  • 3
    Is the VAF biologically plausible? Tumor VAF 5–50% is normal for a somatic mutation. Exactly 50% in the tumor and the normal = germline het. Near 0% in both = likely noise. >50% in tumor = possible LOH event.
  • 4
    Are the strand counts balanced? Compare tumor F1R2 and F2R1 for the alt allele. Both should have reads. All alt reads on one strand = orientation artifact, even if it passed filtering.
